# POO_SistemaManutencaoIndustrial
Repositório para o desenvolvimento de um projeto, para a matéria de POO no curso de Engenharia de Controle e Automação, da Universidade Júlio de Mesquita Filho no campus ICTS Sorocaba. Tratando de um sistema que irá monitorar, acompanha a manutenção, realiza a gestão de técnicos e tipos de manutenção e estoque de peças para devidos consertos.
